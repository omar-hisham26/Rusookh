# Rusookh (رسوخ) — HTML / CSS / JS Vanilla Edition

تحويل كامل وتطابق 1:1 لمشروع موقع **رسوخ (Rusookh)** من React / Vite / TypeScript إلى **HTML5 و CSS3 و Vanilla JavaScript فقط**، بدون أي بيئة بناء أو حزم خارجية معقدة.

---

## 🌟 المحتويات والمميزات (Features)

- **Three.js 3D Orb & Particles**: نفس المجسم ثلاثي الأبعاد الأصلي مع التشوه الحركي (Distortion)، السحب الجزيئية (600 Particles)، والتفاعل مع الماوس والتمرير.
- **Glassmorphism**: تصميم زجاجي مطابق مع مؤثرات Blur و `glass-strong` و `glow-electric`.
- **Cursor Glow Follower**: هالة نيون تتبع حركة مؤشر الفأرة بسلاسة (Spring Physics).
- **i18n Localization**: نظام تحويل فوري بين العربية (الافتراضية RTL) والإنجليزية (LTR) وحفظ الخيار في `localStorage`.
- **Lucide Icons**: جميع الأيقونات الأصلية عبر CDN خفيف.
- **Pure & Clean**: لا يتطلب تثبيت `node_modules` أو `bun` أو أي أدوات سطر أوامر.

---

## 🚀 طريقة التشغيل (Run)

افتح ملف `index.html` في أي متصفح مباشرة، أو شغّل خادم محلي:

```bash
python -m http.server 3000
```
ثم افتح: [http://localhost:3000](http://localhost:3000)
