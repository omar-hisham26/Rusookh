# 🎬 RUSOOKH (رسوخ) — The Cinematic Cyber-Studio 2026

مشروع موقع **رسوخ (Rusookh)** الجديد كلياً، المصمم والمبني بهوية سينمائية نادرة وغير نمطية، مستوحى من تقنيات وهندسة المؤثرات في مستودع `Unclecheng-li/AI_Animation` ومحركات الحركة التفاعلية الحديثة، مع التخلص التام من طابع قوالب الـ AI الجاهزة والمكررة.

---

## 🌟 أبرز مميزات المشروع الجديد (Cinematic Features)

1. **🎬 وضع المخرج السينمائي (Film Director Mode)**:
   - تشغيل آلي لتسلسل المشاهد السينمائية بنسب الشاشات السينمائية (2.39:1 Letterbox Bars) وحبيبات الفيلم (Film Grain).
   - توجيه حركة الكاميرا بين الفصول: الافتتاحية -> مسرح القدرات -> المحاكي المعماري -> استعراض المشاريع -> الطرفية -> نقطة الانطلاق.

2. **🔊 محرك الصوت الإجرائي المدمج (Web Audio API Sound Engine)**:
   - محرك صوتي كامل يعمل في المتصفح تلقائياً وبدون أي ملفات صوتية خارجية (`zero external mp3`).
   - مؤثرات: طنين كوني خافت (Cosmic Drone)، أصوات هوائية سينمائية (Whooshes)، نقرات واجهة لمسية متقدمة (Tactile Clicks)، رنين الانتقال بين البطاقات (Card Shifts)، وأصوات نبضات حزم البيانات.
   - زر تحكم سلس في كتم وتشغيل الصوت في شريط الأدوات العلوي.

3. **🎴 مسرح البطاقات ثلاثي الأبعاد (3D Coverflow Card Theater)**:
   - مسرح منظوري ثلاثي الأبعاد حقيقي (`perspective 1400px` + `rotateY` + `translateZ`).
   - تفاعل مباشر مع حركة الماوس (3D Specular Tilt & Glare).
   - تحكم بالأسهم أو السحب أو النقر المباشر على البطاقات.
   - 5 ركائز هندسية لاستوديو رسوخ: تطبيقات الجوال 120fps، منصات الويب الفائقة، أسراب الوكلاء الأذكياء (Autonomous AI Agents)، المتاجر عالية الحمل، والتصميم السينمائي الفاخر.

4. **⚡ محاكي المعمارية البرمجية التفاعلي (Interactive Architecture Reactor)**:
   - محاكاة حية لنقل حزم البيانات بين طبقات النظام (العميل -> بوابة الحافة WAF -> نواة الذكاء -> الخدمات الميكروية -> قاعدة البيانات المشفرة).
   - زر «إطلاق حزمة بيانات تجريبية» مع رنين صوتي ومتابعة لحظية في سجل الـ Telemetry.

5. **📱 معرض المشاريع الواقعية (Flagship Production Reel)**:
   - استعراض واقعي لمشاريع رسوخ الحقيقية:
     - **ريبالانس (Rebalance)**: منظومة التغذية واللياقة الذكية.
     - **فايرو (Viro)**: منصة التوصيل والخدمات اللوجستية الفورية.
     - **نواة رسوخ السحابية (Rusookh Core)**: إطار أتمتة المنشآت والوكلاء الأذكياء.
   - بطاقات زجاجية تفاعلية تتجاوب مع إمالة الماوس بانعكاسات ضوئية حية.

6. **💻 طرفية نواة رسوخ التفاعلية (Rusookh Kernel Console v3.15)**:
   - طرفية تفاعلية حية تتيح للزائر كتابة الأوامر (`help`, `stack`, `philosophy`, `projects`, `contact`, `clear`) أو الضغط على الأزرار السريعة.

7. **🌐 ثنائية اللغة المتكاملة (العربية / English)**:
   - اللغة العربية الافتراضية مع دعم كامل للاتجاه من اليمين لليسار (RTL)، خطوط عربية فاخرة (`Alexandria` و `Cairo`).
   - زر تبديل سلس إلى الإنجليزية دون إعادة تحميل الصفحة.

## 🚀 طريقة التشغيل والمعاينة المحلية (How to Run)

المشروع مبني بمرونة تامة وبدون تعقيدات في التثبيت. يمكنك معاينته فوراً بإحدى الطرق التالية:

### 1. تشغيل عبر بايثون (الأسرع والموصى به):
```bash
python -m http.server 3000
```
ثم افتح في المتصفح: [http://localhost:3000](http://localhost:3000)

### 2. فتح مباشر:
يمكنك ببساطة النقر المزدوج على ملف `index.html` لفتحه في أي متصفح حديث (Chrome / Edge / Safari / Firefox).
